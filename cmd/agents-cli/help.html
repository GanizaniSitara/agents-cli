AGENTS-CLI(1)

Windows · build {{BUILD}}

NAME

agents-cli — list, read and control existing agent CLI sessions.

USE

agents-cli ls
agents-cli tail 12345 --lines 20
agents-cli send 12345 --stdin < message.txt
agents-cli wait 12345 --idle-for 10s --timeout 10m

Replace 12345 with the intended session's PID. Inspect it before sending. message.txt contains your instruction; the redirection example is for cmd.exe. Output is JSON. If the EXE is not on PATH, use .\agents-cli.exe.

COMMANDS

ls [--fast] [--tool T]List sessions. --fast: metadata only.
tail REF --lines 20Read the visible console.
send REF --stdinSend text and Enter. --no-enter: type only.
key REF enterSend a key: enter, escape, ctrl-c, ctrl-u, tab, arrows, backspace.
wait REF --idle-for 10sWait for idle. Also: --timeout 10m, --match REGEX.
name REF "label"Give a session a local label.
adopt PID --tool TRegister an unrecognised session. Optional: --name L.
mute REF / unmute REFDisable / enable screen polling.
stop REFPreview a session stop. Add --confirm PID to kill its process tree.
sends --since 1d --limit 50Read the send/key audit: caller, target and outcome; no message text.
stops --since 7dRead the session-stop log.
version / helpBuild information / full command syntax.

REF: PID, registered label, task name or unique name/title substring. Prefer a PID when targeting matters. A send timeout or submitted:false does not mean nothing was delivered; read tail before retrying.

WATCHER

agents-cli watch start
agents-cli watch list
agents-cli watch stop

A background panel showing sessions that need attention. It does not send instructions. watch stop stops the watcher; stop REF stops an agent.

watch monitors / watch desktops list displays. Start options: --monitor N, --stable 2s. No automatic start at sign-in.

PANEL

Click / double-click rowBring forward / white locator pulse.
Ctrl+Win+ZFirst eligible displayed row; skips parked sessions.
Ctrl+Alt+Shift+1–9,0First ten displayed rows. Both shortcut sets are configurable.
Park / ^Move idle session to bottom / unpark. Parking lasts until watcher exit.
x / Hide / ExitDismiss row / hide panel / stop watcher. Agent keeps running.
Drag headerMove panel. Settings → Reset location restores its position.

Settings controls selection blinking, foreground activation and desktop switching. A normal pulse matches the row colour.

IDLE: idle, not proof of completion. NEEDS INPUT / QUESTION / REVIEW: check the session. ERROR: error detected. RUNNING: work detected. ACTIVE: focused window. UNKNOWN: state unavailable. PARKED: manually put aside. Detection is heuristic; the console is authoritative.

DIAGNOSE

Run watch list. Check build_commit, last_reader_error, last_console_error and reader_restarts.

WR101 start failed       WR102 no heartbeat
WR103 invalid data       WR104 watchdog timeout
WR105 reader exited      WR106 pipe failure
WR107 discovery failed   WR108 console unreadable

Local files: %LOCALAPPDATA%\agents-cli (watcher state, send/stop logs). Review before sharing: status and click logs may include private names/titles. Logs begin with the updated EXE; they cannot recover earlier activity.

Portable EXE. Offline help: Settings → Help, or agents-cli help --open.
